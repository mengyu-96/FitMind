# FitMind 项目文档

基于《项目计划书.txt》v3.0 与《商业计划书.txt》v1.0 编制。范围基线 **v1.0，C01—C10已确认**；当前文档修订 **v1.3，2026-09-25，微信小程序首版收束与自主授权深化**。

用户已接受C01—C10建议基线；Conda环境与SSH仓库已建立。按最新要求，当前M0只交付微信小程序的文字教练、自由记录、简洁计划、主动反馈和数据管理。热力图、实时训练工作台、离线推送、完整管理Web及商业化后置。Agent可在当前任务或一次明确授予的持续范围内自由组合工具、主动调整并给回执，不逐工具请求确认。业务应用尚未实现，验收案例均为规格；旧12周/43.36万元为原范围情景，需要按收束后范围重估。原始材料保持不变。

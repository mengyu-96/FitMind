# FitMind 项目文档

基于《项目计划书.txt》v3.0 与《商业计划书.txt》v1.0 编制。范围基线 **v1.0，C01—C10已确认**；当前文档修订 **v1.2，2026-09-25，智能体自由度与主动信息获取深化**。

用户已接受C01—C10建议方案；Conda后端环境与SSH仓库已建立。本轮深化开放记录、自由目标与计划、可组合能力、有限委托、主动提问与反馈：先保存真实信息，按当前任务补充必要证据，让Agent自主选择有价值的问题与行动。新增32个开放场景、24个自由度及12个主动性验收案例，并同步功能、前后端、数据与接口。业务应用尚未实现，这些案例为待执行规格。预算和排期仍为计划假设，模型与云供应商按G1验证决定。原始材料保持不变。

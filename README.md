# FitMind 项目文档

基于《项目计划书.txt》v3.0 与《商业计划书.txt》v1.0 编制。范围基线 **v1.0，C01—C10已确认**；当前文档修订 **v1.4，2026-09-25，微信小程序使用中反馈与返回续接优化**。

用户已接受C01—C10建议基线；Conda环境与SSH仓库已建立。当前M0交付微信小程序文字教练、自由记录、简洁计划、主动反馈和数据治理。热力图、实时训练工作台、离线推送、完整管理Web及商业化后置。Agent可在明确当前任务中组合已实现工具并给回执，不逐工具请求确认。旧12周/43.36万元为原范围情景，需要按收束后范围重估。原始材料保持不变。

v1.4进一步取消默认离线教练消息与未读积压：使用中自然反馈，用户返回时先看当前任务，选择有价值的轻提示或安静，不每次问候、不补发催促。外部订阅只保留为用户指定事项的待验证实验，不预排V1上线。规则与新增10项RC验收见[主动交流策略](docs/28-主动提问反馈与信息获取策略.md)。

## 已正式开工：G1 基础闭环

开发分支 `codex/m0-foundation` 已实现第一条可运行闭环：PostgreSQL 自由对象与不可变修订、幂等回执、认证隔离、记录/计划交互、当前任务Agent变更、数据导出删除和三个小程序入口。DeepSeek `deepseek-flash` 已完成真实工具回合联调，模型密钥只保存在本机 `.env`。

AppID 已登记，正式微信登录仍待 AppSecret；知识库专家审校与入库、持续委托、生产鉴权、真机联调和 M0 验收仍待完成。

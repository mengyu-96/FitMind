# 产品需求规格说明书（PRD）

版本：v1.0｜日期：2026-09-25｜状态：C01—C10建议方案已由用户确认

## 1. 首版范围

P0为MVP发布必要能力，P1为MVP体验增强或V1，P2为远期。P0包括登录与授权、文字对话、建档、动态卡片、计划草稿及确认、训练记录、肌肉图、动作设备库、知识引用、站内提醒、历史与导出删除、内容审核。支付、语音、动作识别、社交、多租户管理均不纳入建议MVP。

## 2. 用户旅程

首次打开 → 了解数据用途并选择授权 → 微信登录 → 每次1—2个问题完成目标/经验/可用时间/器材/限制建档 → 确认摘要 → 生成计划草稿 → 用户采纳 → 执行或对话补录 → 确认完成 → 查看肌肉图和依据 → 次日反馈与后续调整。

用户可跳过非必要问题；信息不足时明确缺口，不推断体重、伤病或训练成绩。拒绝健康信息授权仍可浏览通用知识，个性化建议功能按缺失条件受限。

## 3. 功能验收规格

| ID/优先级 | 用户故事与规则 | 可验收结果 |
|---|---|---|
| F01/P0 | 发送文字、查看历史、重试失败消息；快捷回复与卡片入口补充对话 | 重试不产生重复训练；同一消息有明确发送/处理中/成功/失败状态 |
| F02/P0 | 对话收集画像，重要字段展示来源和确认状态 | 未确认目标不作为已接受计划；修改目标保留旧版本 |
| F03/P0 | Agent创建自定义内容卡，用户编辑、移动、隐藏、归档、删除 | 未知类型仍可阅读；冲突返回最新版本；删除卡不连带删除训练事实 |
| F04/P0 | 按时间、器材、经验、限制生成计划；用户确认后生效 | 计划包含日期/动作/组次/负重口径/休息/注意事项；冲突条件必须先澄清 |
| F05/P0 | 开始训练、每组记录、暂停恢复、跳过、结束、补录和修订 | 单位明确；重复提交仅一条事实；未做动作不计入完成量 |
| F06/P0 | 人体前后图、肌肉明细、最近训练、趋势、询问教练 | 无数据为未知；显示估算标签、更新时间和算法版本；颜色与数值一致 |
| F07/P0 | 动作详情展示步骤/错误/器材/替代/来源，设备详情展示适用动作 | 不存在场馆位置时显示“未提供”；没有版权媒体可用审核文字替代 |
| F08/P0 | 专业回答检索知识，查看来源，提交错误反馈 | 引用能定位到有效版本片段；无充分证据明确说明，不能编造书页 |
| F09/P0 | 同意后按个人时间进行站内提醒，可关闭或延后 | 关闭后不再生成对应提醒；静默期间延期；同一触发不重复 |
| F10/P0 | 跨会话记住已确认偏好和训练，可纠正错误记忆 | 被纠正事实不再召回；个人记忆不会进入公共知识库 |
| F11/P0 | 查看数据用途、撤回授权、导出与注销 | 登录隔离；注销后阻断访问，按保留策略清除派生数据 |
| F15/P0 | 编辑提交知识草稿、专家审核、发布/撤回、处理反馈 | 未审核版本不进检索；撤回立即从查询层排除 |
| F03/P1 | 卡片合并拆分、批量排序、多类型注册管理 | 预览受影响卡片及关联，不重复复制事实 |
| F12/P1 | 会员支付、到期、退款、配额 | 在支付能力单独批准并完成T12后上线 |

## 4. 状态规则

- 计划：draft → active → superseded/archived。每用户同时仅一个active主计划；采纳新计划原计划变superseded，已开始训练持有原计划快照。
- 训练：draft → in_progress ↔ paused → completed；draft/in_progress/paused可取消为cancelled。completed仅走修订流程，不重新完成。
- 卡片：active ↔ archived → deleted；hidden是展示属性，不是删除状态。
- 建档：not_started → collecting → awaiting_confirmation → completed；后续修改产生画像版本。

## 5. 异常和边界

“今天练了卧推”只能识别意图，缺组数重量时先询问或保存不参与负荷计算的草稿。“两只20kg哑铃”保存每只20kg和数量2；不能直接混同杠铃总重。训练中感到疼痛可立即结束，不为完成目标催促继续。未成年人和治疗康复需求在建议首版引导退出个性训练服务。

断网可编辑当前训练草稿，恢复连接后按版本同步；界面明确“未同步”，清缓存风险不能伪装为云端保存。AI不可用时仍可查看计划和记录训练。账号切换清理本地个人缓存。

## 6. 产品度量

北极星指标：每周完成有效训练记录且查看反馈的用户数（同一用户周内去重）。激活定义：注册后7天内完成建档确认、采纳计划、至少一次有效训练。D7留存定义：注册日为D0，第7个自然日再次产生核心行为的比例；按Asia/Shanghai统计。健康信息和原始对话不进入分析事件。

首轮内测建议激活率≥40%、D7核心行为留存≥25%、训练记录纠错率<10%；这些是验证门槛，不是行业事实或业绩承诺。

# 产品需求规格说明书（PRD）

版本：v1.2｜日期：2026-09-25｜状态：按用户要求深化开放业务、智能体自主性及主动信息获取

## 1. 首版范围

P0为MVP发布必要能力，P1为MVP体验增强或V1，P2为远期。P0包括登录与授权、文字对话、建档、动态卡片、计划草稿及确认、训练记录、肌肉图、动作设备库、知识引用、站内提醒、历史与导出删除、内容审核。支付、语音、动作识别、社交、多租户管理均不纳入建议MVP。

详细功能流程见22，业务规则见23，基准场景见24。开放对象、任务就绪与自主执行以[25-智能体自由度与柔性业务内核](25-智能体自由度与柔性业务内核.md)为准，开放场景见26、自由度验收见27，主动提问与反馈以[28-主动提问反馈与信息获取策略](28-主动提问反馈与信息获取策略.md)为准。不扩展到收费、医疗、视频识别等新的商业阶段。

## 2. 用户旅程

用户从提问、记录、即时训练需求或长期目标任一入口开始→检查该能力必要的身份/用途→Agent完成可做部分→保存有依据的自述→按当前任务选择主动反馈或关键追问→逐步形成画像/计划/视图→在明确意图或有限委托内执行→持续反馈与回访。完整建档和固定表单不是前置流程。

用户可跳过非必要问题；信息不足可以先形成正式个人记录，只限制确实依赖缺失证据的计算或动作。拒绝健康信息授权仍可浏览通用知识；会话内主动提问使用当前授权和相关语境，离线触达另需通知用途。Agent应主动验证观察、询问体验、吸收回应，而不是只等待用户填字段。

## 3. 功能验收规格

| ID/优先级 | 用户故事与规则 | 可验收结果 |
|---|---|---|
| F01/P0 | 发送文字、查看历史、重试失败消息；快捷回复与卡片入口补充对话 | 重试不产生重复训练；同一消息有明确发送/处理中/成功/失败状态 |
| F02/P0 | 渐进画像、自由目标与个人属性，无统一必填清单 | 不依赖完整画像的任务可直接完成；自述/推测分开；目标变更有来源和版本 |
| F03/P0 | Agent创建自定义内容卡，用户编辑、移动、隐藏、归档、删除 | 未知类型仍可阅读；冲突返回最新版本；删除卡不连带删除训练事实 |
| F04/P0 | 自主生成单次/轮换/日期计划与多模块方案；明确意图/有限委托内可执行调整 | 灵活叙述与可执行节点分开；消费某项数据才校验必要证据；保留旧事实及变更回执 |
| F05/P0 | 自由/部分/复合记录，按需映射组数据，支持执行与纠错 | 不完整自述可正式保存；补齐不双计；未知值不补造，单位和可比性按消费者校验 |
| F06/P0 | 人体前后图、肌肉明细、最近训练、趋势、询问教练 | 无数据为未知；显示估算标签、更新时间和算法版本；颜色与数值一致 |
| F07/P0 | 动作详情展示步骤/错误/器材/替代/来源，设备详情展示适用动作 | 不存在场馆位置时显示“未提供”；没有版权媒体可用审核文字替代 |
| F08/P0 | 专业回答检索知识，查看来源，提交错误反馈 | 引用能定位到有效版本片段；无充分证据明确说明，不能编造书页 |
| F09/P0 | Agent主动提问、解释观察、获取体验反馈、维护关注议程；授权后个性回访 | 会话内不被固定提醒模板限制；已回答/拒绝主题不重复问；后台另守授权与频控 |
| F10/P0 | 跨会话记住已确认偏好和训练，可纠正错误记忆 | 被纠正事实不再召回；个人记忆不会进入公共知识库 |
| F11/P0 | 查看数据用途、撤回授权、导出与注销 | 登录隔离；注销后阻断访问，按保留策略清除派生数据 |
| F15/P0 | 编辑提交知识草稿、专家审核、发布/撤回、处理反馈 | 未审核版本不进检索；撤回立即从查询层排除 |
| F03/P1 | 卡片合并拆分、批量排序、多类型注册管理 | 预览受影响卡片及关联，不重复复制事实 |
| F12/P1 | 会员支付、到期、退款、配额 | 在支付能力单独批准并完成T12后上线 |

## 4. 状态规则

- 计划：draft → active → superseded/archived；draft可归档。每用户同时仅一个active主计划；review_status=valid/needs_review/blocked独立表达是否允许启动。采纳新计划原计划变superseded，已开始训练持有原计划快照。
- 计划项：scheduled/in_progress/completed/partial/skipped/missed/cancelled，与实际训练会话分开，不能把过期计划当已完成训练。
- 训练：draft → in_progress ↔ paused，in_progress/paused均可completed；专用完整补录命令允许draft→completed；draft/in_progress/paused可取消为cancelled。completed仅走修订流程，不重新完成；部分完成也可保存，删除另用deleted_at。
- 卡片：active ↔ archived，两者均可→deleted；hidden是展示属性，不是删除状态。关联卡编辑路由至源对象，自有内容卡可编辑content。
- 建档：not_started → collecting → awaiting_confirmation → completed；后续修改产生画像版本。

建档状态仅保留旧旅程兼容含义，不再控制是否允许服务。开放对象lifecycle=active/archived/deleted；活动自述状态与projection_status分离，finished+partial允许存在。上述training_sessions状态机仅适用于标准训练投影，不能阻止无组明细的源记录保存。个人议程状态按28独立管理，不要求问题全部回答才可继续。

## 5. 异常和边界

“今天练了卧推”可直接保存用户训练自述，不追造组数重量；Agent可主动问感受或选择不打扰。补充信息后更新同一活动并重算可用投影。“两只20kg哑铃”按有证据口径保存；未知重量不是0。训练中不适可以停止并记录已做部分，不为完成目标催促继续。成年人一般健身服务边界不变。

计划长度与组织由任务决定，7日只是模板；有效一次指令或有限委托可授权未来局部调整，超出范围再确认。计时/复合活动可记录，A0仍只覆盖适用证据；标准工作组、源自述和实际可计算范围分开统计。时间range/unknown也可保存，不能为匹配日历伪造日期。自定义字段、类型、视图和主动议程按25/28运行。

断网可编辑当前训练草稿，恢复连接后按版本同步；界面明确“未同步”，清缓存风险不能伪装为云端保存。AI不可用时仍可查看计划和记录训练。账号切换清理本地个人缓存。

## 6. 产品度量

北极星指标：统计周内完成至少一次有效work训练且在同周查看对应/同期反馈的用户数（用户周内去重）。激活定义：注册后7×24小时内完成建档确认、采纳计划、至少一次有效训练。D7留存定义：注册日为D0，第7个自然日再次产生核心行为的比例；按Asia/Shanghai统计。个人训练日历按发生时区快照，不能与服务经营口径混用；修订、删除、零分母等以23 BR-15为准。健康信息和原始对话不进入分析事件。

上述v1.1“结构化训练闭环”指标保留用于历史可比，标metric_definition_version=1；不能驱动产品强制用户建档填表。v1.2并列观察first_value（首次获得有用答复/已保存记录/可用方案）、开放记录留存、问题相关性、反馈采纳率和重复追问率，定义版本单独记录，未实测前不将旧40%/25%门槛机械移用。跨对象补齐按activity_id去重。

首轮内测建议激活率≥40%、D7核心行为留存≥25%、训练记录纠错率<10%；这些是验证门槛，不是行业事实或业绩承诺。

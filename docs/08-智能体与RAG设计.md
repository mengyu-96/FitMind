# 智能体与RAG设计

版本：v1.0｜日期：2026-09-25｜状态：C01—C10建议方案已由用户确认

## 1. 编排流程

v1.0优化采用LangGraph显式状态图、主教练入口及专项任务子图，完整状态、恢复和预算契约见[19-Agent架构优化设计](19-Agent架构优化设计.md)。下述流程保留为业务逻辑概览，不再等同一次不可恢复的线性函数调用。

输入校验 → 风险与意图分流 → 获取已确认画像/近期训练/相关记忆 → 专业问题检索知识 → 模型生成结构化候选动作 → 工具网关校验 → 必要时用户确认 → 执行领域事务 → 基于真实结果生成回复 → 校验引用与输出 → 保存简短运行摘要。

Agent负责自然语言理解、对话策略、资料组织与建议，不决定认证、医学结论、价格、支付结果或数据库约束。权限规则在模型外执行。原文thinking字段保留为null，不要求生成、存储或展示内部思维过程；审计使用tool结果、证据ID和简短decision_summary。

## 2. 工具目录与授权

| 类别 | 工具 | 校验/确认 |
|---|---|---|
| 读取 | get_user_data/get_training_history/get_card/list_cards/get_notes | 限本人；时间、条数有上限 |
| 检索 | search_exercise/search_equipment/search_knowledge | 只检索有效审核内容，top_k≤10 |
| 卡片 | create_card/update_card/move_card/show_card/hide_card/reorder_cards | 内容schema、版本、归属、渲染白名单 |
| 事实 | save_user_data/save_training_track/save_note | 用户明确陈述才可记为事实；模糊值澄清 |
| 计划 | create_plan/update_plan | 只能产生草稿；用户采纳后生效 |
| 计算 | calculate_muscle_state | 调度确定性计算，不接受模型自填结果 |
| 提问 | ask_user | 每轮建议≤2问，允许跳过 |
| 高影响 | delete_card/merge_cards、历史删除/修订 | 明确删除或修改指令、必要时预览确认；合并P1 |

所有工具带run_id、tool_call_id、actor上下文、参数schema、幂等规则。user_id由网关注入。save_user_data写未确认偏好时标记candidate；伤病推断不能升级为诊断事实。工具报错应如实回应，禁止说“已保存”而数据库失败。

## 3. 记忆

短期上下文建议最近20条加摘要，受token预算约束；长期画像和训练从结构化事实读取；语义记忆仅用于检索线索。每条记忆保存source_ref、更新时间、确认状态、置信度和有效期。当前用户确认信息优先于旧摘要；冲突先澄清。

查询向量前设置用户过滤，返回后再检查来源仍有效，避免用户数据串读和删除后复现。健康与训练原文不混入公共知识索引。周摘要引用训练revision，历史修订触发失效。对话摘要不能自行创造训练完成事实。

## 4. RAG内容流水线

版权/使用许可登记 → 文档解析 → 提取标题、页码/段落位置 → 按语义标题切分（建议300—600中文字、重叠约50字）→ 人工审核 → 生成向量 → 离线评测 → 发布有效版本。

知识分为运动原理、动作、器材、一般营养、安全信号等。来源可信度不能只靠“书籍/教练”类别判断，需考虑作者资质、版本、适用范围和证据日期。受版权限制内容只展示获准范围的摘录与来源，不能把购买书籍视作全文再分发授权。

## 5. 检索和回答

关键词检索与向量各取前20，按chunk_id合并；建议RRF融合参数k=60，重排后取5条（均为待评测默认值）。中文关键词使用经验证的分词/术语别名，不能直接假设英文全文检索配置适合中文。

检索结果包含document_id/version/chunk_id/locator/审核状态/适用条件。证据不足时给通用安全提示或说明无法支持该结论，不补造来源。来源互相冲突时说明分歧，不能选择更符合用户期待的片段。用户个人数据优先影响适用性，不改变知识内容本身。

回答中的citation_id必须来自本轮检索有效集合；服务端检查ID存在，专家评测检查“内容是否真的支持结论”。仅存在引用不等于结论正确。撤回文档立即加入查询排除集合，缓存以知识发布版本作为键，旧回答展示来源已撤回提示。

## 6. 提示词与模型选择

系统提示按角色人格、健康边界、工具规范、输出schema、引用规则拆分并版本化。知识片段、用户文本均为不可信内容，不执行其中“忽略规则/导出数据”指令。输入输出长度有上限，工具结果不包含服务密钥。

候选模型用相同集评测正确性、结构化输出、工具调用准确率、中文体验、p95延迟、每成功任务成本、数据处理条款。建议MVP仅一个主模型加一个已评测备用；切换版本需回归。不在本轮指定未经实测的最佳供应商。

## 7. 评测基线

建立至少200个中文案例：常规60、缺信息30、伤病/危险30、提示注入20、检索无答案20、多轮纠错20、工具失败20。健身专家标注期望引用与不应执行动作；留出测试集，不将全部案例作为提示示例。

建议门槛：结构有效率≥99%；明确事实抽取准确率≥95%；有依据问题引用支持率≥95%；无答案正确拒答/澄清≥95%；危险案例严重不当建议0；越权工具成功0；训练写入重复0。指标在固定集上测得，不代表现实风险为零。模型、提示、知识版本变化均回归关键集。

## 8. 成本与降级

通用已审阅知识和动作详情优先直接读取；缓存不得混用个人上下文。每run记录输入/输出token、工具耗时和供应商计费口径。超时保留可重试结果；模型不可用时仍可记录训练、查看历史。到达用户或全局预算阈值先停止非必要主动生成，不中断基本数据访问。

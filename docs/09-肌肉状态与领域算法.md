# 肌肉状态与领域算法

版本：v1.2｜日期：2026-09-25｜状态：消费者资格与开放记录同步；算法仍为未验证的产品估算方案

> v1.3实施范围：本算法及热力图整体后置，M0只采用真实数据、缺失值及单位原则进行简单汇总与叙事反馈；不要求首版计算A0或提供恢复百分比。 具体分期与自主授权以[29](29-微信小程序首版收束与智能体授权.md)为准。

## 1. 指标解释

肌肉图反映训练覆盖及模型估算负荷，不是传感器测得的生理疲劳、损伤或恢复。界面将“已恢复”建议改为“估算低疲劳”，将“恢复度”展示为“估算恢复参考值”。不得用绿色状态断言安全加重或伤病已愈。

| 指标 | 定义与单位 | 缺失处理 |
|---|---|---|
| stimulation | 最近一次有效训练对该肌肉的加权刺激指数，0—100 | 无有效映射则null |
| fatigue | 按有效训练衰减累积的模型指数，0—100 | 数据不足为null |
| recovery | 100-fatigue，模型参考指数 | fatigue为空则为空 |
| strength | 对应动作的个人训练表现，保留动作和负重口径 | 不推断单块肌肉真实力量 |
| frequency | 最近7×24小时内含该肌肉有效映射次数work组的已完成会话数，按effective_at去重 | 无符合条件训练为0；与全部训练次数区别显示 |
| trend | 同动作、同口径、可比较训练的变化 | 可比样本不足为unknown |
| circumference | 用户自填部位围度cm | 无数据为null，不从训练推算 |

## 2. 肌肉字典

保留原文胸/背/肩/臂/腿/核心和细分追踪意图。采用一个canonical muscle_id，跨部位展示用标签，如三角肌后束不复制成两个肌肉。肌束/功能区域和独立解剖肌肉分开标注；“上腹/下腹”“胸大肌中束”等名称须专家审核，不把习惯称谓都当独立肌肉。

建议MVP先覆盖20—30个可解释追踪区域，准确数量由资产和专家审核确定；原文细分项保留在后续字典，不伪造缺失映射。左右侧只有实际记录侧别才拆分；双侧数据不能自动推断左右不对称。

## 3. 可复现的候选算法A0

用于建立可测试基线，所有系数需要健身专家审核及内测校准，未经验证不宣传为运动科学测量结果。

对未删除的已完成训练会话i、肌肉m，令每组映射权重w在[0,1]。仅completed=true、set_kind=work、measurement_type=reps且有有效映射的组进入A0。有效组贡献：`e = w × q`；q按整数RPE建议为1—5取0.5、6—7取0.75、8—10取1.0，未知取0.75且降低置信度。热身、跳过、计时组、无动作映射的组不纳入A0负荷计算，记录仍保留。重量保留用于动作表现，不在此算法中跨动作累加公斤数。

会话负荷 `L(i,m)=min(100, 8 × sum(e))`。最近符合条件会话stimulation=L。当前fatigue：`min(100, sum(L(i,m) × 2^(-elapsed_hours/48)))`，只使用effective_at不晚于as_of的有效已完成会话，elapsed_hours=(as_of-effective_at)/小时。exact精度的effective_at=ended_at，date精度采用23 BR-08明示的derived_effective_at并降低置信度。48小时为候选衰减半周期，并非生理恢复定律；首版不凭模型自由调整个人半周期。

计算使用全部有效事实；性能优化可使用含算法版本的检查点，不能无说明截断14天导致突变。内部保留小数，展示取整；分类使用未取整数值。历史修订/删除从事实重算，不以“减去一次事件”修复。

例：某肌肉4组，w=1，RPE8，则L=32；24小时后fatigue≈22.63、recovery≈77.37；如果刚新增同负荷会话，fatigue≈54.63。重复处理同一会话结果不变。此例验证算术，不验证医学有效性。

## 4. 颜色与优先级

| 状态 | 条件（建议） | 显示 |
|---|---|---|
| unknown | 没有可用历史或有效映射 | 灰色+数据不足，不展示100恢复 |
| inactive | 有历史，但最近7天无有效刺激 | 灰色+近7天未记录训练；保留估算详情 |
| low | 近7天有数据且0≤fatigue<40 | 绿色+估算低疲劳 |
| light | 40≤fatigue<60 | 黄色+估算轻疲劳 |
| moderate | 60≤fatigue≤80 | 橙色+估算中疲劳 |
| high | 80<fatigue≤100 | 红色+估算高疲劳 |

疼痛和不适以独立醒目标记覆盖一般建议，不由颜色阈值判断；长期高指数可提示复核训练安排，不能诊断“过度训练综合征”。原文35=轻度的示例统一修正为low。

## 5. 动作表现与趋势

可选择在同动作1—10次有效负重记录上显示Epley估算：e1RM=重量×(1+次数/30)，但仅在动作适用、口径一致且用户知晓估算条件时使用。自重、辅助、不同器械配重、左右单侧不得直接比较；MVP可只展示实际最高相同次数成绩。

趋势建议比较最近14天与前14天同动作同负重口径的中位e1RM，每窗≥3个可比会话，差值>5%上升、<-5%下降，否则稳定；任一窗口不足则unknown。该阈值是产品假设，不把短期变化宣传为肌肉增长。

热量仅在活动类型、时长和体重均已知时，采用经过审核的MET来源计算估计值；力量训练不直接从吨位换算热量。MVP可不展示热量数值，保留原需求待方法审核；不得制造精确消耗。

## 6. 置信度与验证

confidence按可用输入完整性给low/medium，不标成统计置信概率。RPE、映射、时间缺失降低等级；涉及深层细分未经审核则不计算。记录algorithm_version、mapping_version、as_of、source_revision。

覆盖率分别返回known_work_sets、eligible_work_sets、unquantified_activity_count及denominator_known。已知组范围内可显示eligible/known，但存在未量化活动时不能称“全部训练覆盖率100%”；总分母未知则总体比例为null。只有确定没有工作组时显示“无工作组”，未报组数显示“组数未知”。只有计时组时状态unknown，不以计算输入空集返回fatigue=0、recovery=100。计时组的训练频次可在普通历史中统计，不能混同本页每肌肉frequency。没有新增训练也需按as_of推进衰减，读侧最多缓存5分钟，同图使用统一时间与事实版本。

验证覆盖空历史、边界40/60/80、24小时衰减、重复事件、乱序事件、跨时区、补录未来时间拒绝、删除后恢复、无侧别、字典重命名。发布前由专家确认用户说明、映射与限制；没有该确认只能用于内部演示。

## 7. 消费者资格与自由记录

上述算法针对满足条件的执行投影，不是源记录准入门槛。动作未映射、日期为范围、未知组数、混合运动和自由感受均可保留；Agent可反馈叙事变化并选择必要追问，不能填造标准组来让算法运行。

未知重量不影响已有有效映射次数work组进入A0，但无法支持依赖可比负重的e1RM。RPE8.5、自定义量表、“很累”等保留原值，不能擅自取整或等价为标准RPE；未有经审核的映射时按A0的RPE未知处理并降低置信度。时间range/unknown不进入当前依赖exact/date的衰减算法，不伪造午夜时刻；date派生时刻仍遵守BR-08且注明精度。

计数按稳定source_activity_id去重，同一活动补充动作/组数只提高资格或更新贡献，不新增一场训练。每个投影绑定source_version，内容失效后旧贡献撤销；异步重算期间显示stale。用户主观感受和数值估算可以并列，不能用估算低疲劳否定用户不适自述。

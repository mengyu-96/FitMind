# 内容运营与增长计划

版本：v1.2｜日期：2026-09-25｜状态：开放价值与主动交流指标同步

## 1. 首版内容资产

| 资产 | 建议初始数量 | 质量要求 |
|---|---:|---|
| 常见力量动作 | 50条 | 步骤、常见错误、适用条件、替代、来源、审核人 |
| 通用器械 | 15类 | 使用方式、调整说明、不同型号差异 |
| 肌肉追踪区域 | 20—30个 | 名称、功能分区说明、动作映射、合法图形资产 |
| 专业知识 | 100篇短条目 | 可溯源、可授权、版本化，不追求堆量 |
| 常见问答 | 100题 | 覆盖无答案和错误认识，不能全部充当测试集 |
| AI评测集 | 至少200例 | 分类与门槛见08，保留独立测试部分 |

数量为工作量假设，可在G1确认覆盖矩阵后调整。比数量更重要的是覆盖首版计划中的每个动作和风险场景；未审动作不能被Agent编入计划。

## 2. 内容生产与治理

内容编辑建立草稿→记录来源和使用许可→专家审核技术内容→独立审核发布→用户反馈→修正或撤回。原则上作者不能自审发布；小团队可以聘请外部专家审阅。所有版本保留修改原因，撤回原因对运营可查。

台账字段：asset_id、名称、类别、来源URL/书籍版本与页码、作者、权利人、许可凭据、可用范围、到期日、审核人、审核日期、有效版本、关联动作和风险标签。仅“参考某教材”不能代替准确来源与许可。

建议每季度复核通用内容，发生争议或来源失效立即复核。安全反馈优先处理，普通纠错目标2个工作日响应（须有实际人力支持）。

## 3. 内测招募与研究

第一轮30—50位成年人，覆盖新手/进阶、不同手机及训练频率；明确知情同意，不要求提供病史证明。研究重点为能否独立建档、是否少填表、是否理解估算、是否持续记录。每周5位访谈观察实际任务，不只收满意度。

第二轮100—300人，在第一轮P0问题关闭后进行；记录激活和留存队列。达到11的门槛再扩至1000种子目标，用户数增长不替代质量指标。

## 4. 埋点字典

| 事件 | 触发 | 允许属性 |
|---|---|---|
| onboarding_confirmed | 画像确认成功 | 渠道、版本、耗时区间 |
| plan_accepted | 服务端采纳成功 | 计划版本、是否首次 |
| training_completed | 事实提交成功 | 会话匿名关联ID、组数区间 |
| muscle_panel_viewed | 面板有效展示 | 入口、是否有数据 |
| knowledge_citation_opened | 用户点击来源 | 内容ID、发布版本 |
| record_corrected | 训练修订成功 | 原因分类，禁用自由文本 |
| reminder_opt_out | 关闭提醒 | 提醒类别 |
| subscription_paid（V1） | 验签后权益生效 | SKU、渠道、净金额 |

不采集对话原文、伤病、体重、开放个人标识到第三方分析。事件按event_id去重，服务器确认事件与页面点击区分；匿名ID仍可能属于个人信息，纳入政策和删除流程。

有效训练、计划履约、组完成率和纠错率统一采用23 BR-15，不能把仅热身、取消、重复完成请求计成有效训练。training_completed仅代表事实提交，分析时还需completion_kind和至少一个work组条件；记录删除/修订发更正事件而不增加新完成次数。经营队列按服务时区与提交时间建队，个人训练日历按发生当地日期，两种口径分别说明。

## 5. 增长实验

| 实验 | 假设 | 指标/停止条件 |
|---|---|---|
| 对话+快捷记录 | 比纯对话减少录入摩擦 | 完成耗时、纠错率；错误增加则停止扩大 |
| 反馈解释 | 显示来源和估算说明改善理解 | 用户能正确解释图例比例；不能以点击率替代理解 |
| 29/39/49价格研究 | 存在可持续订阅支付意愿 | 意愿与真实购买分开统计；仅V1收款 |
| 健身房试点 | 现场推荐提高激活 | 每渠道CAC、激活、D30留存 |
| 提醒偏好 | 用户自定时间减少打扰 | 关闭率、训练周活；不追求发送量 |

实验提前登记主要指标、队列、时长、预算和退出条件；小样本只做探索，不宣称统计显著。不同人群或周次不能直接作为公平A/B对照。付费转化分母在14中为MAU，实验漏斗可另用合格曝光人数但必须注明。

## 6. 客服与用户材料

上线帮助页覆盖：如何开始、如何对话补录、哑铃单只/总重、纠正记录、肌肉图含义、来源反馈、通知管理、导出注销。客服处理建议先查request_id和状态，未经用户授权不索取完整健康对话。提供“无法使用/记录错误/建议不适合/隐私请求”四类入口。

用户快速上手草案：直接说想了解什么、想做什么或刚做了什么；教练先提供帮助，再按需要了解情况。记录可简可详，计划可单次或持续；在肌肉面板查看有数据支持的估算。感觉不适时停止相关训练，必要时寻求专业帮助；随时调整教练的提问方式、提醒及个人数据设置。

## 7. v1.2价值与主动交流评估

旧onboarding→plan→标准training漏斗保留metric_definition_version=1，便于历史对比，不代表所有用户的必经路径。新增first_value事件按任务回执记录首次有效知识回答、源记录成功或可用建议；其中回答质量仍须抽样评测，消息送达不等于提供价值。

新增activity_saved/activity_enriched（按源活动ID去重）、inquiry_presented、inquiry_resolved、feedback_corrected及interaction_preference_changed。分析只用目的类别、状态、耗时区间、脱敏关联ID与版本，不上传问题/答案正文、自定义字段值或敏感主题标题。源/标准训练事件不能重复累加场次。

主动性评估有用问题比例、答案吸收正确率、重复追问率、拒答后重问、错误观察及用户负担；不把回答率或资料完整率当唯一目标。开启提醒、深入访谈与少问用户分别研究，不为提高回复率扩大通知。至少覆盖只记一句话、无计划用户、自定义目标与自定义量表用户。

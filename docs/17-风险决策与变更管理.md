## 3. 变更流程

提交CR编号→描述问题与收益→评估需求ID、接口、数据、内容、测试、排期、费用与隐私影响→给出方案→项目负责人确认→修订文档版本→实施与回归→关闭。紧急线上修复可先按预授权应急流程止损，但事后补记录。

新增收费、健康敏感处理、跨境供应商、公开上线、多租户或治疗场景必须重新评估，不属于普通文字调整。小范围字段修正也需同步07与06，避免接口和数据库漂移。

## 4. 模板

变更单：CR-ID、提出人、日期、现状、目标、关联F/T/ADR、方案、替代方案、工时/费用变化、风险、验收、批准结果、实施版本。

决策单：问题、背景、选项、推荐、取舍、证据、决定人、日期、复核条件。

会议纪要：讨论事项、已决定、未决定、负责人、截止时间、关联版本。没有明确决定的讨论不能当作开工授权。

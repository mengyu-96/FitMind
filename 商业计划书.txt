# FitMind 健身智能体 · 投资介绍

**文档版本**：v1.0
**最后更新**：2026-09-14
**文档说明**：本文件面向投资方，不含技术细节，聚焦市场机会、产品价值、商业模式与增长潜力。


## 一、一句话介绍

**FitMind 是一个像真实私教一样的 AI 健身教练，通过对话陪伴用户训练，追踪每一块肌肉的进步，并拥有可溯源的专业健身知识库。**


## 二、我们看到了什么问题

### 2.1 传统健身 App 的通病

市面上的健身 App 大多是一个"记录工具"——用户需要自己填表、自己选计划、自己记数据。它们的问题在于：

- **不主动**：不会关心你今天状态怎么样，不会问你昨天练完腿疼不疼
- **不专业**：只有动作名称，没有标准做法，没有常见错误提示
- **不个性**：所有人看到一样的计划、一样的界面
- **不陪伴**：没有真实教练的沟通感和督促感
- **不追踪**：只知道"你练了胸"，不知道"你的胸大肌上束恢复得怎么样"

### 2.2 真实私教的痛点

真实私教能解决上述问题，但：

- **贵**：一线城市私教课 300-800 元/节，长期负担重
- **时间受限**：约课、通勤、时间固定
- **质量参差**：教练水平不一，专业度难以保证
- **无法随时陪伴**：训练时不在身边，练完就失联

### 2.3 市场空白

**没有人把"真实私教的陪伴感"和"AI 的随时在线"结合起来。**


## 三、我们的解决方案

### 3.1 产品定位

**一个像真实私教一样的 AI 健身教练。**

它不是工具，是教练。它不只是回答问题，而是主动关心你、了解你、陪伴你。

### 3.2 核心能力

**能力一：对话式陪伴**

用户不需要填表、不需要点按钮。像跟教练聊天一样，说"我今天练了卧推"，它就会记录、分析、给建议。

它会主动找你：

- "你上次练腿是3天前了，今天要不要安排一下？"
- "我发现你卧推进步了，要不要试试加点重量？"
- "你上周说膝盖不舒服，现在好点了吗？"

**能力二：每一块肌肉都看得见**

这是 FitMind 最核心的差异化能力。

传统 App 只告诉你"胸肌 80%、背肌 60%"。FitMind 追踪到**每一块肌肉**——胸大肌上束、中束、下束，三角肌前束、中束、后束，肱二头肌长头、短头……

用户打开小程序，看到的是一个**人体热力图**：

- 绿色 = 已恢复
- 黄色 = 轻度疲劳
- 橙色 = 中度疲劳
- 红色 = 重度疲劳
- 灰色 = 未训练

点击任意一块肌肉，可以看到它的刺激度、疲劳度、恢复度、力量水平、训练频率、趋势，以及最近练了什么、推荐练什么。

**能力三：点开任何动作和设备都能看详情**

用户在训练计划里看到"上斜哑铃卧推"，点一下就能看到：

- 动作演示图
- 目标肌肉（哪块肌肉主要发力、哪块协同）
- 标准做法（一步一步）
- 常见错误（耸肩会练到斜方肌）
- 替代动作（没有哑铃可以用什么）
- 需要什么器械、器械在哪、怎么调

点开"上斜哑铃凳"，就能看到：

- 设备图片
- 在健身房的位置
- 可调节角度
- 能做什么动作
- 使用提示

**能力四：拥有专业健身知识库**

FitMind 不是靠大模型"瞎编"，而是拥有一个**可溯源的专业健身知识库**，涵盖：

- 基础理论（运动解剖学、训练原理）
- 动作库（每个动作的标准做法）
- 器械库（每个器械的使用规范）
- 训练计划（增肌、减脂、力量、康复）
- 营养知识
- 康复与安全

当用户问"上斜哑铃卧推怎么做"，它会从知识库检索，回答时标注来源："参考《力量训练解剖学》"。

**能力五：为每个人定制**

每个用户看到的界面可能完全不同：

- 新手看到的是"基础动作学习"
- 老手看到的是"周期化训练"
- 有伤病的用户，康复训练放在最显眼位置
- 用户说"我膝盖不舒服"，系统会自动创建一张"膝盖状态"卡片

### 3.3 用户使用场景

**场景一：新手入门**

小王第一次去健身房，不知道怎么练。他打开 FitMind：

- 智能体通过对话了解他的情况（身高、体重、目标、时间）
- 为他制定适合新手的计划
- 每个动作都可以点开看怎么做
- 训练后问问他感受，记录到肌肉面板

**场景二：进阶突破**

老李练了两年，卧推卡在 80kg 很久了。他打开 FitMind：

- 智能体查看他的训练轨迹和肌肉状态
- 发现他的胸大肌上束恢复很好，但训练频率低
- 建议增加上斜动作，调整计划
- 两周后卧推突破 85kg

**场景三：伤病恢复**

小张膝盖不舒服，但还想训练。他告诉 FitMind：

- 智能体记录膝盖状态，创建卡片
- 调整计划，避开对膝盖压力大的动作
- 推荐替代动作
- 三天后主动回访："膝盖好点了吗？"

## 五、商业模式

### 5.1 收入来源

| 来源 | 说明 | 优先级 |
|:---|:---|:---|
| **会员订阅** | 月付/年付，解锁完整功能 | 高 |
| **健身房合作** | 为健身房提供定制版，按会员数收费 | 高 |
| **私教赋能** | 为私教提供工具，提升服务效率 | 中 |
| **知识付费** | 专业课程、训练计划 | 中 |
| **品牌合作** | 器械、补剂品牌合作 | 低 |

### 5.2 定价策略

| 版本 | 价格 | 功能 |
|:---|:---|:---|
| 免费版 | 0 | 基础对话、基础计划、基础记录 |
| 会员版 | 29-49元/月 | 完整肌肉追踪、专业知识库、个性化计划 |
| 健身房版 | 按会员数 | 定制版、数据看板、会员管理 |
| 私教版 | 按教练数 | 教练端、学员管理、计划工具 |

### 5.3 单位经济模型

| 指标 | 说明 |
|:---|:---|
| 获客成本 | 通过健身房合作、社交裂变降低 |
| 用户生命周期 | 健身是长期需求，留存率高 |
| 毛利率 | 软件产品，边际成本低 |
| 付费转化 | 核心功能（肌肉追踪）驱动付费 |


## 六、产品差异化

### 6.1 核心壁垒

**壁垒一：肌肉级追踪**

市面上没有产品做到"逐块肌肉追踪 + 人体热力图可视化"。这是 FitMind 最核心的差异化。

**壁垒二：专业知识库**

不是靠大模型瞎编，而是有可溯源的专业知识库。回答时标注来源，建立信任。

**壁垒三：智能体自主性**

不是预设流程，而是智能体自主决策。每个用户看到的内容都不同。

**壁垒四：对话式交互**

用户不需要学习成本，像聊天一样使用。

### 6.2 与竞品对比

| 功能 | Keep | 乐刻 | 超级猩猩 | FitMind |
|:---|:---|:---|:---|:---|
| AI 教练 | 弱 | 无 | 无 | 强 |
| 肌肉追踪 | 整体 | 无 | 无 | 逐块 |
| 专业知识库 | 无 | 无 | 无 | 有 |
| 对话交互 | 弱 | 无 | 无 | 强 |
| 主动陪伴 | 无 | 无 | 无 | 有 |
| 人体热力图 | 无 | 无 | 无 | 有 |

| 风险 | 应对 |
|:---|:---|
| 用户不愿对话 | 降低门槛，主动引导，快捷回复 |

## 十二、愿景

**让每个人都能拥有一个真正懂自己、有专业知识、能看到自己每一块肌肉进步的 AI 私教。**

我们相信，健身不应该是有钱人的特权。每个人，无论在哪里，无论预算多少，都应该拥有一个懂他的教练。

FitMind，就是那个教练。
